## Условие задачи: классификация числа
Задача: функция `classify(n)` возвращает -1 для отрицательного `n`, 0 для нуля и 1 для
положительного `n`. Нужно показать, как выглядит HIR этой функции и как по HIR строится CFG.
Задача не берётся из банка тренажёра: это минимальный пример на ветвления без циклов.
Вход `n` — целое число. Выход — одно из трёх значений. Для примера достаточно HIR-псевдокода
и CFG из базовых блоков, без машинных инструкций.

## Идея HIR для classify
В HIR сохраняем два последовательных условия. Первое условие проверяет `n < 0`; ветка true
сразу возвращает -1. Второе условие проверяет `n == 0`; ветка true возвращает 0. Если оба
условия ложны, возвращается 1. HIR не содержит скобок и точек с запятой, но содержит операции
сравнения, переходы и возвраты. Такая форма удобна для построения CFG: каждое условие станет
блоком с двумя рёбрами.

## Код classify на C++
Функция `classify` содержит два последовательных ветвления и три точки выхода. Для CFG важны
условия и возвраты, а не имена переменных. Код ниже компилируется как C++17; в примере нет
циклов и вызовов других функций.
```cpp
int classify(int n) {
    if (n < 0) return -1;
    if (n == 0) return 0;
    return 1;
}
```

## Базовые блоки CFG для classify
Обозначим блоки: B0 — вход и проверка `n < 0`; B1 — возврат -1; B2 — проверка `n == 0`;
B3 — возврат 0; B4 — возврат 1; EXIT — выход. Рёбра: B0 -> B1 при true, B0 -> B2 при false;
B2 -> B3 при true, B2 -> B4 при false; B1, B3, B4 -> EXIT. Ветка B1 не соединяется с B2,
потому что после `return` управление не продолжается.

## Трассировка CFG для classify(-5) и classify(0)
Для `n = -5` условие `n < 0` истинно, поэтому выполняется путь B0 -> B1 -> EXIT. Блок B2
на этом пути недостижим. Для `n = 0` условие `n < 0` ложно, затем `n == 0` истинно:
B0 -> B2 -> B3 -> EXIT. Для `n = 7` оба условия ложны: B0 -> B2 -> B4 -> EXIT.
Трассировка показывает, что CFG покрывает все три возврата и не содержит пути B1 -> B2.
