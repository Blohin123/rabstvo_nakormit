## HIR
HIR (High-level Intermediate Representation) — высокоуровневое промежуточное представление программы,
сохраняющее циклы, ветвления, вызовы и типы. Пример: узел `while` в HIR хранит условие и тело цикла.
HIR используют до низкоуровневых оптимизаций и генерации кода.

## CFG
CFG (Control Flow Graph) — ориентированный граф возможных переходов управления в функции.
Вершины CFG — базовые блоки, рёбра — переходы. Пример: условный переход даёт два ребра, true и false.

## AST
AST (Abstract Syntax Tree) — дерево разбора исходного кода, отражающее синтаксическую структуру.
AST ближе к тексту программы, чем HIR. Пример: узел `if` в AST хранит условие, ветки и синтаксические детали.

## Базовый блок
Базовый блок — максимальная последовательность инструкций с одним входом в первую инструкцию
и одним выходом после последней. Внутри блока нет ветвлений, кроме последней инструкции.
Пример: три подряд идущих присваивания без меток образуют один базовый блок.

## Ребро CFG
Ребро CFG — направленный переход между базовыми блоками. Ребро может быть условным или безусловным.
Пример: ребро из блока условия `if (n < 0)` в блок возврата -1 существует для истинной ветки.

## Точка выхода функции
Точка выхода функции — узел CFG, в который ведут рёбра от всех `return` и аварийных завершений.
Точка выхода нужна, чтобы анализ видел все пути завершения функции. Пример: в `classify` рёбра
от трёх `return` ведут в общий узел EXIT.

## Доминатор
Доминатор блока B — блок, через который проходят все пути от входа функции до B. Доминаторы
используют для поиска циклов и построения SSA-формы. Пример: блок условия `while` доминирует
блок тела цикла, если попасть в тело можно только через это условие.

## SSA-форма
SSA-форма (Static Single Assignment) — представление, в котором каждая переменная получает значение
только один раз. SSA-форма упрощает анализ данных и оптимизации. Пример: вместо повторного
присваивания `x = x + 1` в SSA вводят новую версию `x2 = x1 + 1`.
